# Earth Information Jukebox: Team QuadCore

NASA Space Apps Challenge 2026 | Chattogram, Bangladesh

## Challenge
The Earth Information Jukebox: pair NASA Earth Information Center
visuals with sonification generated in real time.

## Idea
An interactive web app that turns NASA Earth data (for example sea ice
or temperature records) into sound, so people can hear climate trends
as well as see them. Users choose a dataset, region and time range.
